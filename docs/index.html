관리자: 새 질의서 처리 7단계

Claude Code에서 “원본 폴더에 새 질의서 올라왔는지 확인하고 처리해줘”라고 하면 audit-question-sync 스킬이 아래 순서로 진행합니다.

  1. 새 원본 찾기Drive 원본/을 끝까지 조회해 처리기록과 비교합니다. 바뀌거나 사라진 원본은 자동 처리하지 않고 알립니다.
  2. 내려받기와 메타 확정파일명 규칙에서 상임위·기관·질의자·제출일·유형을 읽고 확인받습니다. 규칙 밖이면 묻습니다. 추측하지 않습니다.
  3. 파싱과 카드 뼈대kordoc으로 파싱본을 만들고 카드 뼈대와 처리기록을 만듭니다.
  4. 카드 채우기파싱본을 읽고 질의 요지, 핵심 수치(원문 표기 그대로), 주제를 적습니다.
  5. 개인정보·공개 구분 확인 (사람)확인 전에는 올리지 않습니다. 비공개 건도 올리지 않습니다.
  6. Drive에 올리기카드·파싱본·목록을 올립니다. 내용이 바뀐 파일은 새로 올린 뒤 옛 파일을 휴지통으로 보냅니다.
  7. 점검과 보고check.py가 오류 0이어야 끝납니다. 처리한 건, 올린 건, 대기 중인 건을 보고합니다.

팀원: 이렇게 물어보세요

기관으로 찾기“작년 가나다진흥원에 낸 질의서 뭐였지?”
내용으로 찾기“집행률 90% 미달 사유를 물은 질의서 찾아줘”
회신 확인“그 질의서 회신 받았는지 확인해줘”
원본 파일명“그 질의서 원본 파일명이 뭐야?”

답에는 항상 카드 id와 원문 위치가 붙고, 목록에 없으면 없다고 답합니다. 수치는 원문 표기 그대로 전하며, 회신·이행은 카드에 기록된 것만 말합니다. 한글 원본은 읽지 않고 파일명만 알려 줍니다.

설치

관리자 PC에는 스킬 두 개를, 팀원 PC에는 조회 스킬만 설치합니다.

git clone https://github.com/yongkyu4803/audit-question-archive.git
cd audit-question-archive
mkdir -p ~/.claude/skills

관리자

cp -R skills/audit-question-sync skills/audit-question-lookup ~/.claude/skills/

팀원

cp -R skills/audit-question-lookup ~/.claude/skills/

준비물: Claude Code, Google Drive 연결, Python 3.10 이상, (관리자) Node.js 20 이상. 한글 문서는 kordoc으로만 읽습니다.

원본 파일명 규칙

한글 파일 안에는 상임위·질의자·제출일이 없습니다. 파일명이 규칙을 따르면 메타를 자동으로 읽고, 따르지 않으면 건마다 묻습니다.

2026-10-14_기획재정위원회_가나다진흥원_홍길동_서면질의.hwpx
제출일YYYY-MM-DD 또는 YYYYMMDD
상임위 · 기관 · 질의자공백과 밑줄 없이 붙여 씁니다
유형본질의 · 서면질의 · 요구자료 · 보충질의 · 종합질의
버전선택. 수정본은 _v2, _v3 (생략하면 v1)

원본/에 올린 파일은 이름을 바꾸지 않습니다. 수정본은 새 파일로 올립니다.

지키는 원칙

  • 확인 전에는 올리지 않습니다. 개인정보 확인은 사람이 하고, 비공개 건은 Drive에 올리지 않습니다.
  • 한글 원본은 팀원에게 공유하지 않습니다. 원본/은 관리자 전용입니다.
  • Drive 원본은 건드리지 않습니다. 이름 변경·이동·삭제 없이 내려받은 사본으로만 작업하고, 원본이 바뀌면 해시로 알립니다.
  • 한글 문서는 kordoc으로만 읽습니다. 없으면 다른 방법으로 대신하지 않고 멈춥니다.
  • 메타와 수치는 추측하지 않습니다. 파일명 규칙이나 관리자 확인, 원문에서 확인한 것만 적습니다.
  • 목록에 없으면 없다고 답합니다. 비슷한 다른 건을 같은 건처럼 말하지 않습니다.
예시의 질의서, 기관, 의원, 수치, Drive 파일 id는 모두 가상입니다. 자세한 설정과 운영 방법은 README를 보세요.
